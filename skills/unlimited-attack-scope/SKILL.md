## The no-limits principle

```
OODA / project blackboard Facts / the verification iron rule / the combination playbook all apply to every security domain. A skill is a framework, not a cage:
  Search everything (multiple channels) · Verify everything (searching ≠ a vulnerability) · Chain everything (small vulnerabilities pieced into a big breach) · Record everything (negative results are Facts too)
  No upper limit (Web/APK/EXE/internal network/cloud/firmware/blockchain/AI/wireless/hardware/social engineering all allowed) · When blocked, change route · Until the target is reached, do not rest
> Given a set of capabilities and a target, derive — like solving a puzzle — the attack chain that belongs uniquely to this target;
> that chain may apply only to your one target in the whole world and be forever unsearchable online, because you derived it on-site.
> That is the true meaning of thinking outside the inherited frame.
```
