# API / reference (example)

## HTTP `/api/skills/{id}`

- `resource_path`: a relative path inside the package, e.g. `FORMS.md`, `scripts/payloads.txt`.
- `depth=summary`: summary and directory only, suited to a first-pass search.

## Multi-agent runtime

- Use the Eino ADK **`skill`** tool to progressively load a skill package; optionally enable `multi_agent.eino_skills.filesystem_tools` to access files inside the package.
