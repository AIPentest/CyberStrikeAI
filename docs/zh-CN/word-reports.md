# 漏洞报告下载

在漏洞管理列表中，点击每条漏洞右侧的下载图标，弹窗选择 **Markdown（.md）** 或 **Word（.docx）**。选择后下载该条漏洞，取消或按 Esc 不会下载。下载失败时保留弹窗，可重新选择。

Markdown 沿用现有内容、界面语言与文件名。Word 包含所选漏洞的基本信息、描述、前置条件、复现步骤、证据、影响、修复建议和复测记录；保留原始状态，待确认或误报不会改写为已确认漏洞。证据作为纯文本导出，不解析其中的 HTML 或 Markdown，也不自动嵌入截图。

此功能不配置自动生成任务，不修改数据库结构，也不保存额外的报告产物。服务器无需安装 Office、Python 或 Pandoc；查看 Word 文件的软件需要中文字体。

Word 下载使用 `GET /api/vulnerabilities/:id/download?format=docx`，要求 `vulnerability:read` 及对应漏洞的资源访问范围，无需额外的文件管理权限。接口也支持 `format=md`，格式参数不合法返回 400，不存在的记录返回 404，越权请求返回 403。Word 正文限制为 8 MiB，超出时返回生成失败。

原有页面级 Markdown 批量导出保持不变。
